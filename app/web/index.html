Authoring Assistant

Your chapters, and what is waiting for you

Welcome

This tool reads one chapter at a time and asks you, one question at a time, whether to link a citation, link a concept page, or add a term to your glossary. It shows you everything before it saves anything.

There is nothing to install and nothing to set up. Everything happens on this Mac.

Optional

If you have a DeepSeek account, the tool can also ask it for extra glossary suggestions. You do not need one — the ordinary checks work on their own, and if DeepSeek is ever unavailable the tool simply carries on without it.

You can add a key now, or at any time, from Settings in the top corner.

What would you like to work on?

Choose a single chapter, or the folder that holds all your chapters.

You will be asked again each time you run the tool. Nothing is remembered between runs.

      One thing is missing
      
  
      To turn a Word document into a chapter, this tool uses a separate free
  program called pandoc. It is not on this Mac yet.
      
  
      Everything else in the tool carries on working exactly as normal — this is
  only needed for Word documents.
      

  
      
    
      What happens if you press the button
      
    
      The tool downloads pandoc's own installer, checks that it really is signed
    by the people who make it, and opens it for you. An installer window appears:
    press Continue, then Install. It asks for
    this Mac's password, which is normal for any installer.
      
    
      The download is about 40 MB, so it takes a minute or
    two. Nothing in your vault is touched, and nothing about the rest of this
    tool changes.
